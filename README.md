# Ejercicio Funciones Semana 14

## Calculadora de compra con funciones en Python

### Descripción del proyecto

Este proyecto corresponde a la actividad de la Semana 14, donde se desarrolla un programa en Python utilizando funciones con parámetros y retorno de valores.

La aplicación permite calcular el total de una compra aplicando un descuento según el porcentaje ingresado por el usuario.

## Objetivos

- Aplicar funciones con parámetros en Python.
- Utilizar valores de retorno mediante `return`.
- Resolver un problema práctico utilizando programación.
- Implementar entrada y salida de datos.

## Funcionamiento

El programa solicita:

- Precio del producto.
- Cantidad comprada.
- Porcentaje de descuento.

Después utiliza la función:

`calcular_total(precio, cantidad, descuento)`

para obtener el valor final de la compra.

## Tecnologías utilizadas

- Python 3
- Visual Studio Code
- Git
- GitHub

## Ejemplo de ejecución

Precio: 10  
Cantidad: 5  
Descuento: 10%

Resultado:
